# Development helpers

For the supported public core path use [the reproduction guide](../../docs/REPRODUCING.md).

These older wrappers support locally built ROS Noetic research workspaces. They
are not needed for the preview checks and do not provide a downloadable image.
Local wrappers require `FL2G_ROOT` (a writable project directory). Remote wrappers
require `FL2G_REMOTE=user@host` and `FL2G_ROOT`; `FL2G_PORT` defaults to 22.
No personal build-host address or external-drive auto-discovery is supplied.
The full ROS linked dependency license boundary is described in
[LICENSING.md](../../docs/LICENSING.md).

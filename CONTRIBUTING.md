# Contributing

This is an experimental research preview. Please include the source tag, exact
configuration, GNSS activation status, trajectory output, scoring reference
point, alignment and association settings when reporting an estimation result.

Run the portable checks in [docs/REPRODUCING.md](docs/REPRODUCING.md) for changes
to the core or tools. Explain any skipped checks and external data requirements.
Keep raw datasets, credentials, private paths, compiled artifacts and container
images outside commits. Preserve component licenses and upstream attribution.

Performance work needs development/evaluation separation and a written protocol
before inspecting sealed evaluation results. Negative outcomes and incomplete
runs belong in the results record. A test-suite pass is not an accuracy claim.
